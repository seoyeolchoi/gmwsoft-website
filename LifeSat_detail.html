HOW IT WORKS

LifeSat 작동 방식

안심밴드를 차고 있으면, 나머지는 AI와 위성이 합니다.

1
안심밴드 착용
손목·반지·목걸이 형태의 전용 안심밴드를 착용합니다. IPX7 방수, 72시간+ 배터리로 등산·해양·일상 어디서든 사용 가능합니다.
IPX7 방수72시간+ 배터리경량 설계
2
생체신호 실시간 측정
심박수, 산소포화도(SpO2), 체온, 낙상(가속도계)을 실시간으로 측정합니다. 착용 초기 7일간 개인 평소 패턴을 학습하여 기준선을 수립합니다.
심박수산소포화도체온낙상감지
3
Edge AI 자동 이상 감지
기기 내장 Edge AI가 개인 기준선과 비교하여 이상을 1차 판단합니다. 인터넷 없이 오프라인으로 작동합니다. 위성 연결 시 Cloud AI(Claude API)가 정밀 분석으로 오탐을 최소화합니다.
Edge AI (오프라인)Cloud AI (정밀분석)오탐 최소화
4
Iridium 위성으로 자동 전송
셀룰러가 없어도 Iridium 위성망(전 지구 극지 포함 100% 커버리지)으로 GPS 좌표와 생체신호 데이터를 자동 전송합니다. 별도 안테나·장비 없이 소형 모듈로 작동합니다.
Iridium 9603전 지구 커버자동 전송
5
가족 스마트폰 즉시 알림
가족 앱에 GPS 지도 링크, 현재 생체신호 요약, 119 자동신고 버튼이 포함된 긴급 알림이 즉시 전송됩니다. SMS 백업도 함께 발송됩니다.
GPS 위치생체신호 요약119 자동신고(선택)

TECHNOLOGY

핵심 기술

AML 이상감지 4년 실전 경험을 생명 안전에 적용한 기술입니다.

🧠
2단계 AI 이상감지
1단계(Edge AI): 기기 내장, 오프라인 작동. 개인 7일 패턴 학습 후 이상 1차 판단.

2단계(Cloud AI): 위성 연결 시 Claude API 정밀분석으로 오탐 최소화. 향후 도메인 특화 소형 LLM 자체 탑재 예정.
🛰️
Iridium 위성통신
전 지구 극지 포함 100% 커버리지. 별도 안테나 없이 소형 모듈(Iridium 9603, 17g) 내장.

지리산 오지, 태평양, 아마존 밀림에서도 50바이트 패킷 전송 가능.
⌚
독립 안심밴드
스마트폰 없이 독립적으로 작동. 심박·산소·체온·가속도 센서와 GPS·위성모듈 통합.

IPX7 방수, 72시간+ 배터리, 종단간 암호화(E2E) 보안 설계.
