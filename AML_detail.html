KEY MODULES

핵심 AML 모듈

금융당국 규정에 맞는 핵심 모듈을 모두 구축합니다.

STR (의심거래보고)
이상거래 자동 탐지 → 심사 → FIU 보고까지 전 과정. AI 기반 STR 초안 자동 생성 기능 포함.
CTR (고액현금거래보고)
일정 금액 이상 현금거래 자동 집계 및 FIU 보고. 예외·면제 관리 포함.
WLF (세계제재리스트 필터링)
UN·OFAC·국내 제재리스트 실시간 대조 및 알림. 일치 고객 차단 및 보고.
KYC (고객확인제도)
신규·기존 고객 위험도 평가, 실소유자 확인, EDD(강화 고객확인) 관리.
RBA (위험기반접근법)
고객·거래·상품·채널별 위험도 점수화. 고액자산가(HNW) 모듈 포함. AI 기반 동적 스코어링.
배치 시스템
월별·일별 자동 배치 실행. 고액자산가 편입·해제 판정, 이상거래 집계 자동화.

AI 기반
AML 자동화

Claude API를 활용한 STR 자동 초안 생성부터 이상거래 패턴 분석까지, AI가 AML 담당자의 업무 효율을 높입니다.

  • ✓ STR 초안 자동 생성 — 담당자 작성 시간 80% 단축
  • ✓ 개인별 거래 패턴 학습 — FP(오탐) 비율 최소화
  • ✓ 동적 RBA 스코어링 — 실시간 위험도 자동 업데이트
  • ✓ 규정 변경 자동 감지 — 금융위·금감원 공시 모니터링

AI STR 자동화 흐름

  • 1
    이상거래 탐지
    AI가 고객 평소 패턴과 비교하여 이상 거래 자동 탐지
  • 2
    STR 초안 자동 생성
    Claude API가 거래 내용 분석 → STR 보고서 초안 자동 작성
